# winget manifests

The first submission of myCat to [microsoft/winget-pkgs](https://github.com/microsoft/winget-pkgs),
as `manifests/y/yumiaura/myCat/<version>/`. After it is merged, every release
tag opens the next version's pull request from CI (`.github/workflows/publish-winget.yml`,
with komac), so these files are not edited by hand per release.
